# Google Sheets 라벨 QR 생성

라벨 시트에서 날짜가 `B2`, 단일 배치 번호가 `B4`일 때 QR을 표시할 칸에 아래 수식을 넣습니다. QR 데이터는 `MM_DD_BATCHNO`입니다. 예를 들어 `2026-09-25`와 `314`는 `09_25_314`가 됩니다.

```gs
=IF(OR($B$2="",$B$4=""),"",IF(AND(ISNUMBER($B$2),$B$2>0,REGEXMATCH(TO_TEXT($B$4),"^[1-9][0-9]{0,11}$")),IMAGE("https://quickchart.io/qr?size=290&margin=4&ecLevel=M&text="&ENCODEURL(TEXT($B$2,"mm_dd")&"_"&TEXT($B$4,"0")),1),"날짜/배치 확인"))
```

이 수식은 QR 이미지를 만들기 위해 **날짜와 배치 번호를 QuickChart에 전송**합니다. 이름·상품·송장번호는 보내지 않습니다. 외부 전송이 허용되지 않는 환경에서는 이 수식을 사용하지 마세요. 브라우저 확장 프로그램의 스캔 처리는 별개이며 로컬에서만 진행됩니다.

`B4`에 `155 + 371`처럼 여러 배치 번호를 적는 경우 위 수식은 QR을 만들지 않습니다. 각 배치 번호를 별도로 QR로 만드는 방식이 필요합니다. 라벨 출력 전 날짜, 배치 번호, QR 스캔 결과를 함께 확인하세요.
