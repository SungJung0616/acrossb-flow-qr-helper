# AcrossB Flow QR Helper — Windows 로컬 확장 프로그램

Chrome 또는 Edge에서 이미 로그인한 AcrossB Flow 페이지에 스캐너 입력 패널을 추가합니다. 별도 서버, Python, Node 설치 없이 사용합니다. 기본값은 **테스트 모드**입니다. 운영 배치 선택/완료 제출은 개발 과정에서 수행하지 않았습니다.

## 프로젝트 개요

반납된 작업지시서의 QR을 스캔해 작업 중 목록에서 **배치 코드 날짜와 배치 번호가 모두 같은 행**을 찾는 브라우저 확장 프로그램입니다. 일치하는 행이 정확히 하나일 때 그 행의 체크박스만 선택합니다. 완전한 목록이 보이지 않거나 화면 구조가 달라졌다면 선택을 중단합니다. 라벨용 QR 생성 방법은 [docs/label-qr-formula.md](docs/label-qr-formula.md)에 별도로 정리했습니다.

구성은 Manifest V3 콘텐츠 스크립트 두 개입니다. `core.js`가 QR 검증·DOM 조사·일치 판정·체크박스 변경을 맡고, `panel.js`가 입력 화면과 결과 기록을 맡습니다. 비밀번호나 쿠키를 읽지 않으며 QR 스캔값을 별도 서버로 전송하지 않습니다.

## 설치

1. 이 저장소를 ZIP으로 내려받아 압축을 풀거나 복제합니다.
2. Chrome은 주소창에 `chrome://extensions`, Edge는 `edge://extensions`를 입력합니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 압축을 푼 폴더 중 `manifest.json`이 들어 있는 `acrossb-flow-qr-helper` 폴더를 선택합니다.
5. 본인이 직접 로그인한 아래 페이지를 엽니다. 이미 열린 경우 새로고침합니다. 새로고침 전에 기존 선택/미완료 입력을 확인하세요.

   https://axb-us-cpm-1.flow.acrossb.io/flow/work-groups?tab=JOB_IN_PROGRESS

6. 오른쪽 아래 QR 패널을 확인합니다. 설치 권한이 회사 정책으로 차단되어 있으면 관리자에게 이 폴더의 검토를 요청하세요. 프로그램이 브라우저 설정을 자동으로 바꾸지는 않습니다.

## 먼저 테스트

- 폴더 안 `tests.html`을 Chrome/Edge로 열고 **안전 테스트 실행**을 누르면 가짜 데이터 기반 테스트를 실행합니다. 인터넷 연결 없이 동작합니다.
- `demo.html`은 가짜 작업 목록과 실제 패널을 함께 표시합니다. `09_25_314`를 입력하여 테스트, 선택, 중복, 취소를 연습할 수 있습니다. 데모의 선택은 가짜 체크박스에만 적용됩니다.
- 실제 AcrossB에서는 기본 **테스트 모드** 상태로 스캔합니다. 정확히 한 행을 찾으면 전체 날짜/배치 코드와 `테스트: 1행 일치 (체크 안 함)`이 나옵니다.

## 사용

1. 필터를 해제하고 창고 전체의 작업 중 목록이 완전히 로딩될 때까지 기다립니다.
2. 패널의 **스캐너 입력**을 클릭합니다. 일반 USB HID 키보드 방식 스캐너를 사용합니다.
3. `MM-DD_BATCHNO`를 스캔합니다. 예: `09-23_473`. 기존 `MM_DD_BATCHNO` 형식도 지원합니다. Enter 접미사가 있으면 자동 처리합니다. Enter가 없으면 **입력 처리**를 클릭합니다. 미완성 QR을 잘못 처리하지 않도록 시간 경과만으로 자동 제출하지 않습니다.
4. **QR 날짜가 배치 코드 날짜임을 확인했습니다**는 기본 선택되어 있습니다. QR 생성 기준이 다른 날짜라면 이 항목을 해제하세요. 실제 사용 시 **테스트 → 실제 선택 모드로 전환** 버튼을 누릅니다. 버튼이 **실제 선택 → 테스트 모드로 전환**으로 표시되면 현재 실제 선택 모드입니다.
5. 정확히 한 행이 선택되면 화면이 그 작업 행으로 이동합니다. 스캔 결과·전체 날짜/배치 번호·로컬 시간을 패널에서 확인합니다.
6. 이 도구가 선택한 기록의 **이 선택 취소**를 누르면 같은 행을 다시 검증한 후 그 체크박스만 해제합니다. 실제 선택 모드에서 사용하세요. 기존 사용자 선택은 취소하지 않습니다. 행이 다시 생성되거나 새로고침된 경우 취소를 차단하므로 사이트에서 직접 확인하세요.

스캐너는 입력창에 포커스가 있을 때만 사용하세요. 프로그램은 다른 앱/입력창의 키 입력을 가로채지 않습니다. 빠르게 동시에 들어온 스캔은 `처리 중: 재스캔 필요`로 기록되며 다시 스캔해야 합니다. 같은 QR의 연속 입력은 현재 상태가 선택이면 `이미 선택됨`으로 처리하여 토글하지 않습니다. 선택을 취소한 다음 스캔하면 다시 선택할 수 있습니다.

## 확인한 실제 UI와 날짜 기준

2026-09-25에 지정된 로그인 페이지를 읽기 전용으로 조사했습니다.

- `고객사 / 배치 코드` 열의 고객사 아래에 `YYYY-MM-DD_BATCHNO`가 표시됩니다.
- QR의 월·일과 번호를 **배치 코드 문자열의 월·일·번호**와 정확하게 비교합니다. 화면 우측의 `#1` 등 순번은 배치 번호가 아닙니다.
- `div[role="button"][tabindex="0"]` 작업 행의 첫 번째 열에 실제 `input[type="checkbox"]`가 한 개 있습니다. 헤더 전체선택 체크박스는 제외합니다.
- 최초 조사에서 작업 중 180배치/DOM 180행을 확인했습니다. 후속 조사에서는 운영 목록이 변경되었습니다. 행 수를 고정하지 않고 매 스캔 당시 탭의 배치 수와 대조합니다.
- 화면에서 날짜를 생성일·출고일로 별도 설명하지 않으므로 그런 의미를 추정하지 않습니다. **확인한 기준은 배치 코드 날짜**입니다. QR이 다른 날짜 기준이면 실제 모드를 사용하지 마세요.
- QR에는 연도가 없습니다. 현재 연도를 덧붙이지 않고 DOM 전체에서 월·일·번호를 비교합니다. 서로 다른 연도를 포함하여 2행 이상 맞으면 `복수 일치`로 차단합니다.

## 안전 조건 및 제한

- 정확한 HTTPS 호스트·`/flow/work-groups` 경로·단일 `tab=JOB_IN_PROGRESS`에서만 동작합니다. 다른 탭/경로에서는 선택·취소를 거부합니다. 페이지 전환 시 패널을 숨기고 테스트 모드로 초기화합니다.
- 현재 UI의 작업 중 탭 선택 표시, 목록 헤더, 날짜 필드 위치, 전체 행 수, 체크박스 수/상태를 검사합니다. 가상 목록·페이지 분할·필터 때문에 전체 행이 없으면 선택하지 않습니다. 검증된 체크박스 선택이 성공한 뒤에만 해당 작업 행을 화면 중앙으로 스크롤합니다. 검색·필터는 조작하지 않습니다.
- 선택 전 목록 안정성을 재검사합니다. 검사 중 페이지나 행이 바뀌면 재스캔을 요구합니다. 숨김, 비활성, 중간 선택 상태, 대화상자, 로딩, 구조 변경은 차단합니다.
- 실제 변경 코드는 확인된 네이티브 체크박스의 `.click()` 한 곳뿐입니다. 좌표 클릭, 행 클릭, 전체 선택, Submit/Complete/작업 완료 버튼 호출은 없습니다. 사이트 자체의 체크박스 이벤트 처리는 사이트가 담당합니다.
- 체크 후 상태가 기대와 다르거나 다른 행 변경이 감지되면 실패로 표시합니다. 이때 자동 재클릭/복구하지 말고 화면을 확인하세요. 운영 사이트의 이벤트 동작을 실제 클릭으로 검증하지 않았습니다.
- 날짜·번호의 앞자리 0, 0번 배치, 공백, 비숫자 번호는 거부합니다. 월/일은 두 자리, 배치 번호는 1~12자리 양의 정수입니다. 실제 페이지에서 관찰한 형식을 기준으로 보수적으로 제한했습니다.
- 확장 프로그램 자체는 네트워크 요청을 보내지 않습니다. 비밀번호·쿠키·토큰·브라우저 저장소를 읽거나 저장하지 않습니다. 이미 로그인한 탭의 화면 DOM만 사용합니다. AcrossB 웹사이트 자체의 기존 통신은 그대로 유지됩니다.
- 로그는 탭 메모리에만 보관하며 새로고침/탭 종료 시 사라집니다. 영구 감사 기록이나 다른 PC 동기화는 없습니다. 열린 탭별로 독립 동작합니다.
- Chrome/Edge 데스크톱용입니다. 실제 USB 스캐너 하드웨어 입력은 이 환경에서 검증하지 않았으며 Enter 키 방식 또는 입력 처리 버튼을 지원합니다.
- AcrossB UI 개편/언어 변경 시 보수적으로 중단하도록 만들었습니다. README와 코드만 바꿔서 조건을 임의로 완화하지 말고 실제 DOM을 재조사하세요.

## 파일

- `manifest.json`: 지정 호스트 콘텐츠 스크립트만 등록. cookies/storage/tabs/debugger 권한 없음.
- `core.js`: QR 파싱, 실제 DOM 식별, 안전 검사, 선택/취소 엔진.
- `panel.js`: 입력·모드·결과·메모리 기록 UI.
- `tests.html`, `tests.js`: 운영 페이지와 분리된 가짜 DOM 회귀 테스트.
- `demo.html`, `demo.js`: 로컬 전용 데모. demo.js는 확장 프로그램에 등록되지 않습니다.

제거: 확장 프로그램 관리 화면에서 이 확장 프로그램을 삭제하고 AcrossB 페이지를 새로고침합니다.
